# Simple Calculator

## Project Description
This is a simple calculator application developed using HTML, CSS, and JavaScript.

It allows users to perform basic mathematical calculations through an easy-to-use interface.

## Technologies Used
- HTML – To create the calculator structure.
- CSS – To design and style the calculator.
- JavaScript – To perform mathematical calculations.

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Clear button (C)
- Display screen
- Simple and user-friendly design

## Project Structure
```text
Simple-Calculator/
│
├── calculator.html
├── calculator.css
├── calculator.js
└── README.md
```

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open calculator.html in your browser.
4. Start performing calculations.

## Learning Outcomes
- Understanding HTML elements.
- Applying CSS styling.
- Using JavaScript functions.
- Handling button click events.
- Accessing HTML elements using getElementById().
